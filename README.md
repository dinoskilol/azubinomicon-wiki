# Azubinomicon Wiki

Das Azubinomicon Wiki ist eine gemeinschaftlich gepflegte Wissenssammlung für
Auszubildende in Deutschland.

## Lokal starten

```sh
npm ci
npx quartz build --serve
```

## Mitmachen

Verbessere einen Artikel oder ergänze einen Beruf und eröffne dafür einen Pull
Request. Die Regeln stehen in [CONTRIBUTING.md](CONTRIBUTING.md).

Live: https://wiki.azubinomicon.de
